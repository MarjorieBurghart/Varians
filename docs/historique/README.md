# Archives historiques de Varians (jusqu'à V0.8.5.26.2)

Ce dossier regroupe les documents produits version par version avant
l'adoption de Git :

- `TEST_REPORT_V*.txt` : rapports de test de chaque version ;
- `PASSATION_V*.md` : addenda de passation de chaque version ;
- `RELEASE_MANIFEST_SHA256.txt` : manifeste d'empreintes de la
  distribution V0.8.5.26.2 telle que livrée en ZIP.

Ces fichiers sont conservés à titre d'archive. Depuis V0.8.6.0,
l'historique est porté par Git et la vérification par les tests
automatiques ; ces documents ne sont plus produits. Le manifeste
SHA-256 ne décrit que l'état de l'import initial (premier commit du
dépôt) et ne correspond plus aux fichiers modifiés depuis.

Les références à ces fichiers dans `README.txt` et dans les autres
documents historiques renvoient désormais à ce dossier.
