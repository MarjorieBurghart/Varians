E. LIMITES DE VALIDATION
- PySide6 non disponible dans l'environnement de validation : interface Qt

- Aucun test en ligne sur un serveur IIIF distant réel dans cette session.
- Les pauses/arrêts ne peuvent interrompre le corps d'une requête HTTP en cours :
  son timeout est de 25 secondes ; l'arrêt agit entre les images.
- Les manuscrits sans copie intégrale requièrent encore l'accès aux images distantes
  pour leurs pages non stockées.
